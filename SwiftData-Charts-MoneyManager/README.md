# Money Tracker

A simple income and expense tracking app built with SwiftData and Swift Charts. The main goal of this project is to improve my skills in data persistence and visualization using Apple's latest frameworks.

## Features
- Add income and expense entries
- Store data persistently using SwiftData
- Visualize financial status with Pie Chart
- Simple and clean UI

## Technologies Used
- SwiftUI, SwiftData, Swift Charts

## How It Works
1. Add Income or Expense  
   - Enter title, amount, category, and date  
2. View Financial Summary  
   - Pie Chart shows the ratio of income and expenses  
3. Persistent Data Storage  
   - All transactions are saved and accessible anytime
